账户配置

一个"账户"对应一个已登录的抖音创作者账号：程序用它的身份登录后，给这里配置的"目标好友"发送消息。可以添加多个账户，互不影响。不清楚下面几项去哪儿找？

添加账户

左侧填完后，所有配置（含每个账号的 cookies）已打包成一个 JSON。进入 GitHub 仓库 Settings → Environments → user-data（没有 user-data 这个 Environment 就先新建一个），在里面的 Environment secrets 区块点 Add secret，新增名为 CONFIG_JSON 的 Secret（不是 Variable），把下面的值粘贴进去即可，不用再逐条添加变量。

⚠️ 注意别走错地方：仓库里还有一个 Settings → Secrets and variables → Actions 页面，那里是 Secrets / Variables 两个并列 tab、创建按钮叫 New repository secret——那不是这里要去的地方。一定要先点进 Environments → user-data 里面，才能看到 Environment secrets 这个专属区块。

CONFIG_JSON
变量名 变量值 查看详情
  • 变量名：复制 "CONFIG_JSON" 这几个字，粘贴到 GitHub Secret 的 Name 输入框。
  • 变量值：复制配置内容本身（最常用），粘贴到 GitHub Secret 的 Value 输入框。
  • 查看详情：只弹窗预览格式化后的完整配置，方便核对有没有填错，不会复制任何内容。
