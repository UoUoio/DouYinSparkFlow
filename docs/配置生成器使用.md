# 配置生成器使用

网址：[https://oilu.cn/DouYinSparkFlow](https://oilu.cn/DouYinSparkFlow)

## 第1步：获取用户名和抖音号

登录 [抖音创作者中心](https://creator.douyin.com/)，按图查找：

![账号信息获取](images/账号信息获取.png)

## 第2步：获取 Cookies

1. 安装浏览器扩展 [Cookie-Editor](https://cookie-editor.com/)
2. 登录 [抖音创作者中心](https://creator.douyin.com/) 并保持该页面打开
3. 打开 Cookie-Editor，导出 Json 格式：

![Cookies获取](images/Cookies获取.png)

## 第3步：添加目标好友

打开[好友私信页](https://creator.douyin.com/creator-micro/data/following/chat)，每添加一个好友按一次回车。

**方式一：按昵称**（匹配模式选 `nickname`）

填对方的原始昵称（不能是备注）：

![好友昵称获取](images/好友昵称获取.png)

**方式二：按抖音号**（匹配模式选 `short_id`，好友改昵称也不受影响）

打开与对方的聊天页，鼠标放在顶部「查看Ta的主页」上会显示抖音号：

![好友抖音号获取](images/好友抖音号获取.png)

## 第4步：填写其余参数

| 参数 | 说明 | 默认值 |
|---|---|---|
| 消息模板 | 用 `[API]` 代表每日一言 | `[盖瑞]今日火花[加一]\n—— [右边] 每日一言 [左边] ——\n[API]` |
| 一言类型 | 按需勾选 | 文学/影视/诗词/哲学 |
| 匹配模式 | nickname 或 short_id | nickname |
| 发送间隔(秒) | 控制发送频率，避免风控 | 5 |
| 日志级别 | Error < Warning < Info < Debug | Info |

其余参数保持默认即可。

## 第5步：复制结果

- GitHub Action 部署：复制右侧 `Environment Secret` 区域的 JSON
- 源码部署：点击「复制 .env 配置文件」

完成，继续看 [Action部署说明](Action部署说明.md) 或 [源代码部署说明](源代码部署说明.md)。
