# 源代码部署说明

> 前提：先完成 [配置生成器使用](配置生成器使用.md)

适用于本地设备、云服务器、青龙/白虎等任务面板。需要 Python 环境基础。

## 第1步：克隆项目

```bash
git clone https://github.com/2061360308/DouYinSparkFlow.git
```

## 第2步：安装依赖

```bash
pip install -r requirements.txt
```

## 第3步：填写配置

项目根目录新建 `.env` 文件，把配置生成器里「复制 .env 配置文件」的内容粘贴进去。

## 第4步：运行

```bash
python main.py
```
